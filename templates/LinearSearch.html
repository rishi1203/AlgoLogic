Linear Search



What is Linear Search:

Linear search, also known as sequential search, is a simple search algorithm that iterates through each element in a list or array sequentially until it finds the target value or reaches the end of the list.

Operations of Linear Search:

  • Sequential Iteration: Iterate through each element in the list or array, starting from the first element.
  • Comparison: Compare each element with the target value to determine if it matches.
  • Termination: If the target value is found, return its index. If the end of the list is reached without finding the target value, return a special "not found" indicator.

    • Application of Linear Search:

  • Unsorted Lists: Linear search is useful for searching through unsorted lists or arrays where other search algorithms like binary search are not applicable.
  • Small Data Sets: It's efficient for searching through small data sets or arrays with few elements.

    • Adavnatge of Linear Search:

  • Simplicity: Linear search is easy to implement and understand, making it suitable for beginners or scenarios where simplicity is preferred.
  • Applicability: It can be applied to any type of list or array, regardless of whether it's sorted or unsorted.

    • Disadvantage of Linear Search:

  • Inefficiency for Large Data Sets: Linear search has a time complexity of O(n), where n is the number of elements in the list. This makes it inefficient for searching through large data sets or arrays with many elements.
  • Poor Performance for Sorted Lists: Linear search performs poorly for sorted lists or arrays compared to other search algorithms like binary search, as it may need to traverse the entire list even if the target value is at the beginning.
